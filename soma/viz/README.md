## `plot_convergence()` — Hero Visual ★

**This is the most important plot in the project. Everything else is secondary.**

### What it shows

Three side-by-side subplots, one per κ value. Each subplot:
- **Cyan line**: `r_learned` history — the empirical honeypot baiting rate measured from the RL policy every 5,000 training steps
- **Purple dashed line**: `r_star` — the closed-form PBE equilibrium value for this κ

The visual story: the cyan line starts random and converges toward the purple line. This shows "RL recovers the game-theoretic equilibrium."

### Input format

```python
convergence_data = {
    0.0: {
        "learned_r_history": [0.12, 0.18, 0.31, ..., 0.42],  # one per 5k-step eval
        "pbe_r_star":        0.43,
    },
    5.0: {
        "learned_r_history": [0.15, 0.22, ..., 0.61],
        "pbe_r_star":        0.62,
    },
    10.0: {
        "learned_r_history": [0.19, 0.28, ..., 0.74],
        "pbe_r_star":        0.75,
    },
}
```

The `learned_r_history` comes from calling `evaluate_mixing_rates(model, kappa)` every `eval_every` steps inside `train_signal_policy_with_history()` in `deception.py`.

### What "convergence" means for the pitch

The plain English version (always prepare this alongside the technical version):

> "The purple line is what game theory predicts the optimal strategy should look like — calculated by solving the equilibrium equations by hand. The cyan line is what our AI learned from scratch, just by playing the game thousands of times and receiving rewards. They match."

### If the lines don't converge

If `r_learned` doesn't approach `r_star` within 100k steps:

1. Check that `model.predict(obs, deterministic=False)` is used in `evaluate_mixing_rates` — deterministic prediction cannot produce mixed strategies.
2. Check that the PBE solver is correct — if `r_star` is wrong, the plot is measuring against the wrong target.
3. Increase `ent_coef` to 0.1 in `SIGNAL_HYPERPARAMS` to encourage more exploration of mixed strategies.
4. Verify that the Bayesian update in `SignalingGameEnv._bayesian_update()` uses the equilibrium likelihood ratios (not the hardcoded 0.6/0.4 placeholder).

The most likely cause of non-convergence is the hardcoded likelihood placeholder in the environment — fix that first.

## `plot_kappa_sweep()` — Theoretical Result Plot

Two subplots:
- Left: `r*` vs κ — shows monotone increase ("more inattentive attacker → defender baits more aggressively")
- Right: `μ*` vs κ — shows attack threshold rising with attention cost

Input: `pbe_results` dict from `kappa_sweep()` in `pbe_solver.py`. Three data points (κ = 0, 5, 10). The function handles the rest.

This plot appears on the theoretical result slide of the pitch deck. It shows the economic logic of the κ sweep without requiring any RL training to understand.

## `plot_detection_rates()` — Layer 2 Capability Evidence

Bar chart of detection rates per attack chain phase with minimum-threshold dashed lines. Shows at a glance whether the PPO agent meets the lateral movement (≥0.50) and impact (≥0.80) thresholds.

Input: `metrics` dict from `evaluate_detection_rates()` in `detection_metrics.py`.

## What to add

### `plot_fpr_calibration()` — add this

```python
def plot_fpr_calibration(
    layer1_scores_clean: np.ndarray,
    layer1_threshold:    float,
    layer4_scores_clean: np.ndarray,
    layer4_threshold:    float,
    save_path: Optional[Path] = None,
) -> plt.Figure:
    """
    Show score distributions and calibrated thresholds for Layers 1 and 4.
    Demonstrates that FPR targets are met empirically.
    """
    fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(10, 4))
    _apply_dark_theme(fig, [ax1, ax2])
    
    ax1.hist(layer1_scores_clean, bins=50, color=COLORS["rl"], alpha=0.7)
    ax1.axvline(layer1_threshold, color=COLORS["compromised"], lw=2, ls="--",
                label=f"Threshold (1% FPR)")
    ax1.set_title("Layer 1: Score distribution on clean data")
    ax1.legend(fontsize=8, facecolor=SURFACE, labelcolor="#e2e8f0")
    
    ax2.hist(layer4_scores_clean, bins=50, color=COLORS["pbe"], alpha=0.7)
    ax2.axvline(layer4_threshold, color=COLORS["compromised"], lw=2, ls="--",
                label=f"Threshold (0.1% FPR)")
    ax2.set_title("Layer 4: Drift score distribution on clean data")
    ax2.legend(fontsize=8, facecolor=SURFACE, labelcolor="#e2e8f0")
    
    plt.tight_layout()
    if save_path:
        fig.savefig(save_path, dpi=150, bbox_inches="tight", facecolor=BG)
    return fig
```

Include this plot in the pitch deck to pre-empt "what's your false positive rate?" questions.
